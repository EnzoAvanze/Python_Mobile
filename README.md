# Python_Mobile

Interfaces Gráficas em Python com Flet

Repositório com exemplos práticos de interfaces de usuário (UI) desenvolvidas em Python utilizando o framework Flet. 
O projeto reúne desde cartões de apresentação até formulários interativos e gerenciadores de lista.  

📌 Telas do Projeto

📄 tela1.py — Cartão de Apresentação Simples
Descrição: Interface minimalista centralizada que exibe o nome do desenvolvedor e seu cargo.  
Destaques: Configuração de alinhamento, dimensões personalizadas de janela e uso de cores personalizadas no fundo.  

💳 tela2.py — Cartão de Apresentação Completo
Descrição: Cartão de visitas estilizado em um bloco branco com bordas arredondadas.  
Destaques:Exibição das informações de contato (e-mail: avanze@gmail.com e telefone: (11) 98454-5813).  
Organização dos elementos em linhas (ft.Row) e colunas (ft.Column).  
Utilização de ícones nativos (ft.Icons.EMAIL e ft.Icons.PHONE).  

✅ tela3.py — Validação de Formulário
Descrição: Interface interativa de boas-vindas com verificação de termos de uso.  
Destaques:Campo de entrada de texto (ft.TextField) para digitação do nome.  
Caixa de seleção (ft.Checkbox) para validação dos termos.  
Lógica condicional: exibe uma mensagem de boas-vindas caso os termos sejam aceitos, ou um alerta exigindo a aceitação.  

📝 tela4.py — Gerenciador de Lista Interativo
Descrição: Aplicação dinâmica para criação e gerenciamento de uma lista de itens.  
Destaques:Adição de novos itens a partir de um campo de texto.  
Botões para aumentar ou diminuir a quantidade de cada item.  
Opção para remover o item da lista.  
Atualização dinâmica do estado da página via page.update().  

🛠️ Tecnologias Utilizadas
Linguagem: Python  
Biblioteca: Flet
